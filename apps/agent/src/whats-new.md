## 2026-11-19
- External agents: owners and admins can add an agent that runs outside Orbit (Settings → Agentic → Agents → New agent → External agent), for example Claude Code, Codex or your own server. People @mention it in its channels or DM it, and it answers in the thread. It does only what its card allows (its channels, projects and permissions); connect it with "Connect as" on the sign-in page, or with an agent token.
- Support email in Tasks: owners and admins connect a support address to a project (Project settings → Support email). Customer email becomes tasks in Open, and replies to them join their task. In the task, **Reply to customer** sends an email (the blue field says to whom) and moves the ticket to Pending; **Internal note** stays a normal comment. When the customer answers, the ticket is Open again. The old Mail preview page is gone. This team's support mailbox is not connected yet.
- Donna and every other agent now work in code mode: instead of a long list of tools, each one finds the right tool by words and runs a short script with it. So agents can use many more tools (for example a TikTok Ads server with 40 tools) and answer with shorter requests. While an agent works, its message shows each step (for example "Searching tasks"). Writes still need your yes in the thread, and imports and bulk changes still show one plan and need one **yes**, as before. Agent sandbox (built, off): custom agents show a new **Sandbox** tool and an Internet access page; sandboxes are off on this server for now.
- Chat: **Report** a message from its menu (a reason and a note); owners and admins see reports in Settings → Reports and can delete the message. **Block** a person from their profile card: their messages collapse for you and they cannot DM you (Settings → Blocked people to undo). Agents now show a readable @handle from their name (for example @research-bot) instead of a long agent-… code. In the iPhone app, Report and Block come with its next update.

## 2026-11-18
- Imports with one yes: when you ask Donna to import a file (for example customers into Shopify) or to change many things at once, she shows one plan with the field mapping and samples, and runs all of it after one **yes**. The thread shows the progress; reply **stop** to end it. Large files: Donna reads a whole spreadsheet or CSV of tens of thousands of rows, or a long PDF or Word file, in one go, and answers questions about it in one reply.
- Owners and admins can suspend a member (Settings → Members → Manage → Suspend member): they are signed out everywhere and cannot sign in until **Resume member**, with the same password. Their data stays. Removing a suspended member from the workspace also lifts that suspension, so their Orbit account is not locked.
- GitHub: a synced task links to its issue ("GitHub issue #12"), and when you remove a label such as owner:<name> from the issue, the person that label's rule assigned leaves the task too (people assigned by hand stay). Fix: in the dark theme, the red mic of the Ask Donna box stays red under the pointer.
- One navigation on the computer: the Classic / New UI choice in Appearance is gone. The sidebar changes with the area (Docs, Chat, Drive, Tasks, Settings) with Back on top, keeps one width on every page (drag its right edge to resize), and a custom theme colours the whole app. Fixes: in chat, Enter sends again on laptops with a touch screen (Shift+Enter makes a new line); on a phone, the rows of Project settings → Rules stack, so long label and owner names fit.

## 2026-11-17
- iPhone: open chats, tasks and lists update live again; no app update needed.
- Settings → Agentic → MCP server shows Orbit's public MCP address for your own agent, with the Codex CLI and Claude Code commands to copy and a link to the step-by-step guide.
- Voice input: the mic is also in the small Ask Donna box. While it listens, the mic turns red with a timer, and "Transcribing…" shows until your last words are in. When the microphone is refused, Orbit checks it once more and the message says why. Windows app: Orbit desktop 0.1.10 types your words on the computer itself, fast, and its account menu → Desktop app has Check for updates, Start with Windows and "Open diagnostics log".
- iPhone app, from its next update: chat, threads, unread counts, the app icon's number, Tasks, Activity, Docs and Drive update by themselves while the app is open (no pull to refresh), and the app opens with your lists from the last time. Chat: @ and # list people and channels, and mentions now notify the person; hold a message to Forward it, share its link or create a task from it; hold Send for "Send later" and your scheduled messages; send stickers; search all conversations with every filter of the web. Tasks: saved views, full filters, List or Board, swipe for done or the trash, and the task trash. Drive: the trash, Move to…, share links, search and sort; Docs pages: Version history, Lock page, Move to, Duplicate, Export and Import from Notion. Settings has every web page now (Billing, Stickers, GitHub, agent tools and Skills, API tokens, Apps, Export, Danger zone); tap the workspace name to create or join a workspace. Workspace apps are in the ☰ menu, and instance admins have Suggest a change and Admin → Feedback & fixes.

## 2026-11-16
- Voice input: tap the mic beside Send (chat, threads, Ask Donna) and speak. Your words show as you talk; you can edit them, and nothing is sent until you press Send. It works in the browser (not in Firefox), in the Windows app from Orbit desktop 0.1.4 (install it once by hand from the download page; it also fixes "Microphone access is off"), in the iPhone app from its next update, and in the Mac app later.
- Donna can move Docs pages, tasks, and Drive files and folders to the trash, many at once after one yes from you. You can restore them from the trash. Donna also writes tables and links on Docs pages correctly now, and older pages with broken tables are repaired.
- Chat webhooks can read their channel: in Edit channel → Integrations, open the webhook's ⋯ menu and turn on "Can read this channel". It is off by default; only the channel's creator and workspace owners and admins can change it. iPhone notifications now come also while you use Orbit on another device, and a tap opens the message in its own workspace. When you ask Donna, the notification comes with her answer, not when she starts working.
- Connect your own agent to Orbit: members can use Codex CLI, Claude Code or another MCP client on their own computer with Orbit's public MCP address. Approve the workspaces and projects once in the browser; Settings → Agentic → Connected apps stops it.

## 2026-11-15
- Donna sees images you send in Chat or in the Ask Donna panel (screenshots, photos): she looks at them herself, with no need to put them in Drive. She sees only images that you can open.
- Label rules now apply to tasks that already have the label: when an owner or admin adds a rule, turns one on, maps an owner: name to a member, or turns on the owner:<name> switch, the open tasks with that label get the person at once. Done and cancelled tasks stay as they are.

## 2026-11-14
- Agents can work on tasks: assign a task to Donna (or another agent), or @mention her in a task comment, and she starts at once with your permissions. She writes her progress and result as a comment on the task, and asks you in your DM with her when she needs your answer or your yes. Unassign her or delete the task to stop her. Agent skills: owners and admins add skills (the open SKILL.md format) in Settings → Agentic → Skills, from GitHub or skills.sh, as a .zip, or written there, and turn each one on per agent; it loads a skill only when a request needs it.
- Tasks: "Add doc" (beside Add relation) links Docs pages to a task; the page shows its Linked tasks, and you see only the pages and tasks you can open. Projects can have milestones and cycles (Project settings → Milestones and Cycles), and a task can have an estimate in points; each shows its progress, and "Move unfinished tasks to next cycle" keeps the moved tasks counted as carried over. Ask Donna to list them, to set a task's milestone, cycle or estimate, or to link and unlink docs.
- MCP, API and Admin: one OAuth connection (for example Claude or Codex) can cover several workspaces, each with its own projects (tick them on the consent page). The public API can move docs, trash them and list their versions, filters tasks by due date, and takes an Idempotency-Key so a retried create makes no second task or comment. Admin → Storage says when a move of files to or from S3 is done, and "Keep deleted files in S3" sets how many days (1 to 365, default 40) a deleted file stays.
- Chat: a # button beside @ mentions a channel or a task. Project settings: each part (General, Access, Statuses, Labels, Rules, Docs…) is its own page in the sidebar, and Project settings → Docs links a teamspace to the project for its docs. Workspace logos: owners and admins upload one in Settings → General (square crop); it shows in the workspace switcher, on invitations, on the connect (consent) page and in the iPhone app. Large images you upload are made smaller on the server (screenshots as sharp, lossless WebP). Double-click an image in a doc to open it, and zoom it with the mouse wheel.

## 2026-11-13
- Orbit for iPhone (beta, by TestFlight invitation): Home, Tasks, Docs, Chat, Drive (browse, open, upload), Activity, phone notifications with the unread count on the app icon, an "Ask Donna…" bar, Share → Orbit from other apps (to a chat, a Drive folder or a new task), and settings for agents, routines, custom emoji, project settings and this iPhone's notifications.
- Tasks: make a project private (Project settings → Access), set Repeat under Due date, drag projects in the sidebar into your own order, and search the trash (owners and admins can delete forever). Type # anywhere to link a task. Images and files in a new task's description are now saved with it.
- Home: choose your own cards (Customize, top right: add, remove, drag to reorder, rows per card), for example My tasks, Unread chat, recent Drive files or Routines; it saves at once. The iPhone app shows the same cards: tap the pencil on its Home to change them there. Excel and csv files in chat or Drive open as a read-only table. The bell beside the workspace name shows your newest notifications, pickers have a search box, and Cmd/Ctrl+K shows results in sections.
- Chat: Unreads also shows threads with new replies, followed or not. A webhook can be a two-way bot (Edit channel → Integrations → Interactivity → Send messages as events) that gets messages and answers in the thread; it replaces Settings → Agentic → Bots. Webhook URLs start with https://orbit-hooks.easytomanage.com (no login). MCP tools can now handle comments, assignees, labels and projects. Sessions not used for 30 days are signed out.
- Drive pictures to Shopify: ask an agent to put a Drive image on a Shopify blog article (as the article's image or in its text), or just into the store's Files. It asks for your yes, then does it in one step and gives you the Shopify link. A custom agent needs the drive_image_to_shopify tool ticked on its card (Settings → Agentic → Agents), and the Shopify app needs file access (write_files; for articles also write_content).

## 2026-11-12
- GitHub comments now sync both ways: a comment on a synced GitHub issue or pull request shows on the Orbit task with the GitHub author's name and picture, and a comment you write on the task is posted on GitHub (edits and deletes too). While the sync is paused, comments stay where they are.
- Tasks with many or long labels no longer push the row wider: a list row shows 2 labels and a board card 3, and a "+N" chip shows the rest on hover or click.
- Label rules: in Project settings → Rules, owners and admins set "if a task has label X, assign person Y". It works when a task is created with the label and when the label is added later (also from GitHub, Discord, the API and Donna). Rules only add people, never remove them. A switch makes owner:<name> labels assign that member. Ask Donna to list or add a rule.
- Owner names: under the owner:<name> switch in Rules, pick a member for an owner: name that matches nobody (for example owner:david-s → David). A mapped name wins over the name match; remove the entry to go back to it.
- Routines and scripts: Donna can now put a saved script on a routine you already have (ask "use the script X in my routine Y"; she asks for your yes first). You can also do it yourself: Settings → Agentic → Routines → Edit → Script. The script and routine windows now fit the screen, and long code scrolls inside its box.
- When a routine's script fails, Donna can fix the script and run it again (at most 2 times). She posts the result and a short note in the routine's thread that says what she changed. The fixed script makes no changes until you approve it on the routine.
- A routine's last run now shows Done or Failed, not "started" forever.
- Videos play in chat: iPhone .mov files and other videos show a player with a picture in the message. Orbit makes a copy that plays in every browser; until then the message says "Processing the video…".
- Big files in chat: files larger than the chat limit now go to Drive → Uploads → the channel's folder (for a direct message, a folder only its members see) and show in the message like any file. The upload goes straight to storage with a progress bar, and "Try again" continues where it stopped.
- Previews of Excel, Word and PowerPoint files (and csv, odt, ods): click the file in chat or Drive to see it as pages, with its cell colors. Click a video or PDF in chat to open it large.
- GitHub labels now come to Orbit: a task synced from a GitHub issue or pull request gets its GitHub labels (all except the project's sync label). A label that the project does not have yet is made with its GitHub color, and a label removed on GitHub is removed from the task. Labels you add in Orbit stay. Labels do not go back to GitHub.
- Each agent now has its own memory (team and private); Donna keeps everything she remembered so far, and Account settings → Agentic → Memories has an agent picker. Donna now notes lasting facts on her own and checks her memory before she says she does not know. The answer level (Short, Normal, Thorough) is set on each agent's card in Settings → Agentic → Agents, and the default model moved there too (the Admin tab is gone).
- Routines can run a saved script: Donna can write a short script that uses her tools, save it ("save this as a script"), and run it on each run of a routine. Its changes need your yes to that exact script; after any change of the script, the routine makes no changes until you approve the new version. See, edit and delete scripts in Settings → Agentic → Routines.
- Test run: the "Test run" button of a routine (or "test my routine" to Donna) runs it now, as you. The result comes only in your DM with Donna, marked "Test run", and nothing is changed or posted: it lists what it would do. Each routine shows its last runs with the result, errors and the tool calls of its script.
- Donna has her own card in Settings → Agentic → Agents, first and marked Default: owners and admins change her instructions and model for the workspace there, and installation admins her name and avatar (the default model is at the bottom of the Agents tab). Each agent card, Donna's too, ticks the connected services (for example TikTok or Shopify) that the agent may use; a new service is on for Donna and off for the other agents until ticked.
- Chat search has new filters: Mentions me, Has link and Threads only (replies in threads), and you can sort by Newest or Oldest. Filters combine with each other and with This conversation, From and Has file. The matched words are marked in the results.
- Recent searches: click the empty search field in a conversation to see your last 10 searches and run one again; Clear removes them. They are saved in your browser only (web and desktop app).
