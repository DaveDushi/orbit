## 2026-11-14
- Chat: a # button beside @ mentions a channel or a task. Project settings: each part (General, Access, Statuses, Labels, Rules, Docs…) is its own page in the sidebar, and Project settings → Docs links a teamspace to the project for its docs.
- Workspace logos: owners and admins upload one in Settings → General (square crop); it shows in the workspace switcher, on invitations, on the connect (consent) page and in the iPhone app. Large images you upload are made smaller on the server (screenshots as sharp, lossless WebP). Double-click an image in a doc to open it, and zoom it with the mouse wheel.
- Tasks: "Add doc" (beside Add relation) links Docs pages to a task; the page shows its Linked tasks, and you see only the pages and tasks you can open. Projects can have milestones and cycles (Project settings → Milestones and Cycles), and a task can have an estimate in points; each shows its progress, and "Move unfinished tasks to next cycle" keeps the moved tasks counted as carried over. Ask Donna to list them, to set a task's milestone, cycle or estimate, or to link and unlink docs.
- MCP, API and Admin: one OAuth connection (for example Claude or Codex) can cover several workspaces, each with its own projects (tick them on the consent page). The public API can move docs, trash them and list their versions, filters tasks by due date, and takes an Idempotency-Key so a retried create makes no second task or comment. Admin → Storage says when a move of files to or from S3 is done, and "Keep deleted files in S3" sets how many days (1 to 365, default 40) a deleted file stays.

## 2026-11-13
- Orbit for iPhone (beta, by TestFlight invitation): Home, Tasks, Docs, Chat, Drive (browse, open, upload), Activity, phone notifications with the unread count on the app icon, an "Ask Donna…" bar, Share → Orbit from other apps (to a chat, a Drive folder or a new task), and settings for agents, routines, custom emoji, project settings and this iPhone's notifications.
- Tasks: make a project private (Project settings → Access), set Repeat under Due date, drag projects in the sidebar into your own order, and search the trash (owners and admins can delete forever). Type # anywhere to link a task. Images and files in a new task's description are now saved with it.
- Home: choose your own cards (Customize, top right: add, remove, drag to reorder, rows per card), for example My tasks, Unread chat, recent Drive files or Routines; it saves at once. The iPhone app shows the same cards: tap the pencil on its Home to change them there. Excel and csv files in chat or Drive open as a read-only table. The bell beside the workspace name shows your newest notifications, pickers have a search box, and Cmd/Ctrl+K shows results in sections.
- Chat: Unreads also shows threads with new replies, followed or not. A webhook can be a two-way bot (Edit channel → Integrations → Interactivity → Send messages as events) that gets messages and answers in the thread; it replaces Settings → Agentic → Bots. Webhook URLs start with https://orbit-hooks.easytomanage.com (no login). MCP tools can now handle comments, assignees, labels and projects. Sessions not used for 30 days are signed out.
- Drive pictures to Shopify: ask an agent to put a Drive image on a Shopify blog article (as the article's image or in its text), or just into the store's Files. It asks for your yes, then does it in one step and gives you the Shopify link. A custom agent needs the drive_image_to_shopify tool ticked on its card (Settings → Agentic → Agents), and the Shopify app needs file access (write_files; for articles also write_content).

## 2026-11-12
- GitHub comments now sync both ways: a comment on a synced GitHub issue or pull request shows on the Orbit task with the GitHub author's name and picture, and a comment you write on the task is posted on GitHub (edits and deletes too). While the sync is paused, comments stay where they are.
- Tasks with many or long labels no longer push the row wider: a list row shows 2 labels and a board card 3, and a "+N" chip shows the rest on hover or click.
- Label rules: in Project settings → Rules, owners and admins set "if a task has label X, assign person Y". It works when a task is created with the label and when the label is added later (also from GitHub, Discord, the API and Donna). Rules only add people, never remove them. A switch makes owner:<name> labels assign that member. Ask Donna to list or add a rule.
- Owner names: under the owner:<name> switch in Rules, pick a member for an owner: name that matches nobody (for example owner:david-s → David). A mapped name wins over the name match; remove the entry to go back to it.
- Routines and scripts: Donna can now put a saved script on a routine you already have (ask "use the script X in my routine Y"; she asks for your yes first). You can also do it yourself: Settings → Agentic → Routines → Edit → Script. The script and routine windows now fit the screen, and long code scrolls inside its box.
- When a routine's script fails, Donna can fix the script and run it again (at most 2 times). She posts the result and a short note in the routine's thread that says what she changed. The fixed script makes no changes until you approve it on the routine.
- A routine's last run now shows Done or Failed, not "started" forever.
- Videos play in chat: iPhone .mov files and other videos show a player with a picture in the message. Orbit makes a copy that plays in every browser; until then the message says "Processing the video…".
- Big files in chat: files larger than the chat limit now go to Drive → Uploads → the channel's folder (for a direct message, a folder only its members see) and show in the message like any file. The upload goes straight to storage with a progress bar, and "Try again" continues where it stopped.
- Previews of Excel, Word and PowerPoint files (and csv, odt, ods): click the file in chat or Drive to see it as pages, with its cell colors. Click a video or PDF in chat to open it large.
- GitHub labels now come to Orbit: a task synced from a GitHub issue or pull request gets its GitHub labels (all except the project's sync label). A label that the project does not have yet is made with its GitHub color, and a label removed on GitHub is removed from the task. Labels you add in Orbit stay. Labels do not go back to GitHub.
- Each agent now has its own memory (team and private); Donna keeps everything she remembered so far, and Account settings → Agentic → Memories has an agent picker. Donna now notes lasting facts on her own and checks her memory before she says she does not know. The answer level (Short, Normal, Thorough) is set on each agent's card in Settings → Agentic → Agents, and the default model moved there too (the Admin tab is gone).
- Routines can run a saved script: Donna can write a short script that uses her tools, save it ("save this as a script"), and run it on each run of a routine. Its changes need your yes to that exact script; after any change of the script, the routine makes no changes until you approve the new version. See, edit and delete scripts in Settings → Agentic → Routines.
- Test run: the "Test run" button of a routine (or "test my routine" to Donna) runs it now, as you. The result comes only in your DM with Donna, marked "Test run", and nothing is changed or posted: it lists what it would do. Each routine shows its last runs with the result, errors and the tool calls of its script.
- Donna has her own card in Settings → Agentic → Agents, first and marked Default: owners and admins change her instructions and model for the workspace there, and installation admins her name and avatar (the default model is at the bottom of the Agents tab). Each agent card, Donna's too, ticks the connected services (for example TikTok or Shopify) that the agent may use; a new service is on for Donna and off for the other agents until ticked.
- Chat search has new filters: Mentions me, Has link and Threads only (replies in threads), and you can sort by Newest or Oldest. Filters combine with each other and with This conversation, From and Has file. The matched words are marked in the results.
- Recent searches: click the empty search field in a conversation to see your last 10 searches and run one again; Clear removes them. They are saved in your browser only (web and desktop app).

## 2026-11-11
- Insert from Drive in Docs: type "/" → Insert from Drive and pick a file. The page always shows the latest version from Drive (images and videos on the page, other files as a card that opens the preview). People without access to the file see a locked card. Ask Donna to add, change or remove a Drive file on a page, or which pages show a file.
- More agents: owners and admins create agents next to Donna in Settings → Agentic → Agents, each with a name, avatar, instructions, tools, model and the channels where it works. @mention one in those channels or send it a direct message; it works with your permissions and asks for your yes before changes, like Donna.
- Routines can use any agent: pick it when you edit the routine in Settings → Agentic → Routines.
- Routines: ask Donna for a recurring job ("every weekday at 9, summarize yesterday in #support"). She does it as you, with your permissions, and posts the result where you chose. See, pause, edit and delete them in Settings → Agentic → Routines.
- Reminders: "remind me at 5pm to call Ana" and Donna sends you a direct message then.
- Send later: the arrow next to Send in chat → Send later…. Your message is posted as you at that time; edit or cancel it in Scheduled messages. Donna can schedule one for you too.
- Follow tasks: you follow a task you created, are assigned to, comment on or are @mentioned in. Each new comment and status change shows in Activity and as a desktop or phone notification (not your own). The Followers field of a task lists who follows and has Follow / Unfollow. Turn it off in Account settings → Notifications → "Comments and status changes on tasks I follow".
- Ask Donna from any page: a small "Ask Donna…" box at the bottom of Tasks, Docs, Drive, Activity, settings and the other pages (not in Chat; web and desktop app; it shows once your ChatGPT is connected in Account settings → Agentic). Press Enter and Donna answers in a panel on the right while you stay on the page. Close the panel and open it again: the conversation is still there.
- Donna knows the page you asked from and the task, Docs page or Drive folder open on it, so "this" means that item. The conversation is your direct message with Donna, so "Open in Chat" shows it in Chat. Changes still ask for your yes, as in Chat.

## 2026-11-10
- Guests: owners and admins can invite outside people to chosen private channels (Settings → Members → Invite, role Guest). A guest sees only those channels, direct messages with people there and their account settings: no public channels, tasks, Docs, Drive or Donna.
- Owners and admins can connect Donna to remote MCP servers that use OAuth, for example TikTok Social: Settings → Agentic → Workspace → Add tool, credential "Sign in with OAuth (Connect)", then sign in and click Authorize. The row shows who is connected and when to reconnect.
- Phones: Settings, Account settings and Admin open as a menu of their pages. The bottom bar has Drive instead of Mail. Task boards stay fast with many tasks, and every card is there when you scroll. A change to many tasks at once shows in each task's activity. A closed GitHub issue or merged pull request moves its task to Done. Comments lose empty lines at the start and end, and sending a comment no longer blanks the page. Loading shows a small ring spinner. In Drive, a click opens a file or folder; tick the box (or Ctrl/Shift+click) to select.
- Chat on phones: Donna's cards and wide tables fit the screen and scroll sideways, the day chip no longer covers text, and repeated steps show once with a count. Desktop app 0.1.3 for Windows: the taskbar shows unread messages, and "Sign in to app" opens its window.
